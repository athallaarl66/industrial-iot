# Password file for Eclipse Mosquitto
# Format: username:password_hash
#
# SECURITY: This file MUST NOT contain plain-text passwords.
# Plain-text passwords are only valid during initial setup with `mosquitto_passwd -c`.
#
# ─── SETUP INSTRUCTIONS ──────────────────────────────────────────────────────
# 1. Copy `infra/.env.example` to `infra/.env`
# 2. Set your desired passwords in `.env`
# 3. Run the following to generate the hashed password file:
#
#    docker run --rm -it eclipse-mosquitto \
#      mosquitto_passwd -b /mosquitto/config/passwords.txt \
#      edge_device <YOUR_EDGE_PASSWORD>
#
#    docker run --rm -it eclipse-mosquitto \
#      mosquitto_passwd -b /mosquitto/config/passwords.txt \
#      backend_service <YOUR_BACKEND_PASSWORD>
#
# ─── EXPECTED USERS ──────────────────────────────────────────────────────────
# edge_device     → used by sensors / MQTT simulator
# backend_service → used by the .NET backend subscriber
#
# The hashed lines will look like:
# edge_device:$7$...hash...
# backend_service:$7$...hash...
